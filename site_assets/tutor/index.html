Checking the tutor…

Enable the local tutor

Run make tutor and open its preview URL. Run make tutor-key in another terminal to save a free-tier Gemini API key in .gemini-api-key, then select Check connection. This file is ignored by Git and is never included in the website.

Create a key in Google AI Studio ↗. Do not paste your key into the conversation.

Questions and recent chat history are sent to Google Gemini when you press Ask. Check connection sends a test request. Answers may be wrong; check the lesson. The tutor cannot run your notebook. Chat stays in this tab and is cleared on reload.
